Run the model on your own CAD export

The model isn't hardcoded to Seattle or Cincinnati. Drop in any CAD/911 export with call coordinates and timestamps, and the full pipeline runs right here in your browser: demand zoning → MEXCLP compliance table → paired static-vs-dynamic queueing simulation → recommended posts. Nothing is uploaded to a server; the file never leaves this machine.
